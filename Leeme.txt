==========================================================
  INVEC - Cómo instalar y correr el proyecto
==========================================================

Es un proyecto en Laravel 12 con MySQL. Yo lo corro con XAMPP,
así que lo más fácil es que lo montes igual.


----------------------------------------------------------
1. PROGRAMAS QUE NECESITAS
----------------------------------------------------------

- XAMPP (que traiga PHP 8.2 o más nuevo)
- Composer 2
- Node.js versión LTS (20 o 22)
- Git
- VS Code

Extensiones de VS Code que te recomiendo:
- PHP Intelephense
- Laravel (la oficial)
- Tailwind CSS IntelliSense


----------------------------------------------------------
2. ACTIVAR EXTENSIONES DE PHP
----------------------------------------------------------

Abre C:\xampp\php\php.ini y quítale el ; del inicio a estas líneas:

    extension=gd
    extension=zip
    extension=fileinfo
    extension=intl
    extension=mbstring
    extension=pdo_mysql

gd y zip son obligatorias, sin esas no funcionan los PDF ni el Excel
y el composer install te va a dar error.
Para revisar que quedaron activas: php -m


----------------------------------------------------------
3. INSTALAR EL PROYECTO
----------------------------------------------------------

En la terminal de VS Code:

    git clone https://github.com/Hernandez25692/CCISur---INVEC.git invec
    cd invec
    composer install
    npm install
    copy .env.example .env
    php artisan key:generate


----------------------------------------------------------
4. CONFIGURAR EL .env
----------------------------------------------------------

El .env.example viene con SQLite y en inglés. Abre el .env y deja
estas líneas así (a las de DB_ quítales el # del inicio):

    APP_NAME=INVEC
    APP_URL=http://127.0.0.1:8000
    APP_LOCALE=es
    APP_FALLBACK_LOCALE=es
    APP_FAKER_LOCALE=es_ES

    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE=invec
    DB_USERNAME=root
    DB_PASSWORD=

    SESSION_DRIVER=file
    CACHE_STORE=file
    QUEUE_CONNECTION=sync

Yo tengo MySQL en el puerto 3307, pero el XAMPP viene en 3306 por
defecto. Si no te conecta, revisa en qué puerto está el tuyo.


----------------------------------------------------------
5. CREAR LA BASE DE DATOS
----------------------------------------------------------

Enciende MySQL en el panel de XAMPP y corre:

    php artisan migrate --seed
    php artisan storage:link

Si te pregunta que la base "invec" no existe y si la quiere crear,
dale que sí (yes).

El seed crea el usuario para entrar:
    Correo:     admin@ccisur.hn
    Contraseña: admin1234


----------------------------------------------------------
6. CORRER EL PROYECTO (CADA VEZ QUE LO VAYAS A USAR)
----------------------------------------------------------

Con MySQL encendido en XAMPP, abre dos terminales en VS Code.

Terminal 1:
    php artisan serve

Terminal 2:
    npm run dev

Y entras a: http://127.0.0.1:8000

Si no vas a tocar estilos ni JavaScript, en vez de npm run dev puedes
correr una sola vez npm run build y ya solo usas php artisan serve.


----------------------------------------------------------
COSAS A TOMAR EN CUENTA
----------------------------------------------------------

- No uses "composer run dev". Trae un comando (pail) que no funciona
  en Windows y te va a tirar error. Mejor las dos terminales.
